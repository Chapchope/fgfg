# Grid-Based FMM - Краткий обзор

## Что это?

Grid-Based Fast Multipole Method (FMM) - высокопроизводительная реализация метода быстрых мультиполей для вычисления электростатических взаимодействий между частицами в 2D (плоскость z=0).

## Ключевые особенности

✅ **O(N) сложность** - линейное масштабирование вместо O(N²)
✅ **Настраиваемая точность** - порядок разложения от 4 до 12+
✅ **Легко заменяемый потенциал** - через ООП интерфейс
✅ **Картезианские мультиполи** - проще и быстрее для 2D
✅ **Равномерная сетка** - без накладных расходов на деревья

## Производительность

## Использование в коде

```fortran
use grid_fmm_mod
use potential_interface_mod

! Настройка
params%p_order = 6        ! Порядок разложения
params%ngrid_x = 30       ! Размер сетки
params%ngrid_y = 30
params%near_range = 2     ! Радиус ближнего поля

! Создание потенциала
potential = create_coulomb_2d_potential()

! Вычисление
call grid_fmm_2d_compute(N, xs, ys, qs, potential, params, phi, fx, fy)
```

## Математика

### Картезианские мультиполи

**Мультипольные моменты:**
```
M_{n,m} = Σᵢ qᵢ · (xᵢ - xc)^n · (yᵢ - yc)^m
```

**Локальное разложение:**
```
φ(x,y) = Σ_{n,m} L_{n,m} · (x - xc)^n · (y - yc)^m
```

### Алгоритм FMM

1. **P2M** - Particles to Multipole (создание моментов)
2. **M2L** - Multipole to Local (дальнее поле)
3. **L2P** - Local to Particle (вычисление из разложения)
4. **P2P** - Particle to Particle (ближнее поле, прямо)

## Создание нового потенциала

```fortran
type, extends(potential_type) :: my_potential
contains
  procedure :: value  ! φ(r)
  procedure :: force  ! F(r)
  procedure :: moment_coefficient
end type
```

Поддерживаемые потенциалы:
- ✅ Coulomb (1/r) - реализован
- 🔄 Yukawa (e^(-kr)/r) - шаблон в документации
- 🔄 Lennard-Jones - требует адаптации
- 🔄 Произвольный - через интерфейс

## Преимущества этой реализации

1. **Простота** - Картезианские мультиполи проще сферических гармоник
2. **Скорость** - Равномерная сетка быстрее адаптивных деревьев для равномерного распределения
3. **Модульность** - Легко заменить потенциал
4. **Производность** - Параметр `p_order` контролирует точность
5. **Документированность** - Подробные комментарии и примеры

## Ограничения

- ❌ Только 2D (z=0)
- ❌ Оптимизирован для Кулоновского потенциала
- ⚠️ Лучше работает для равномерного распределения частиц

## Расширения

Для 3D или неравномерного распределения смотрите адаптивный FMM в ваших наработках (`fmm_adaptive_mod.f90`).
