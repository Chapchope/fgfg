## 🔧 Как улучшить до 10^-6 - 10^-10

### Вариант 1: Еще больше NEAR_RANGE (самый простой)

```fortran
integer, parameter :: NEAR_RANGE = 10  ! Было 7
```

**Результат:**
- Точность: ~1% (может лучше)
- Скорость: медленнее, но все равно O(N)

### Вариант 2: Полный M2L до p=6 (правильный)

Нужно добавить ~100 строк формул в `translate_M2L_correct`:

```fortran
! Octopole (p=3)
if (P_ORDER >= 3) then
  ! ~10 формул
end if

! Hexadecapole (p=4)
if (P_ORDER >= 4) then
  ! ~15 формул
end if

! p=5
if (P_ORDER >= 5) then
  ! ~21 формула
end if

! p=6
if (P_ORDER >= 6) then
  ! ~28 формул
end if
```

**Откуда брать формулы:**
- Beatson & Greengard (1997) - Section 3
- White & Head-Gordon (1994) - Appendix
- Или вывести самому из ∂^n∂^m(1/R)

**Результат:**
- Точность: 10^-6 - 10^-8
- Скорость: та же (~0.02s для N=1000)
- Работы: 2-4 часа (выписать и отладить формулы)

### Вариант 3: Рекурсивный M2L (элегантный)

Реализовать общий алгоритм вычисления производных 1/R.

**Псевдокод:**
```fortran
function deriv_1overR(n, m, dx, dy, R)
  ! Базис
  if (n==0 and m==0) return 1/R
  if (n==0 and m==1) return -dy/R³
  if (n==1 and m==0) return -dx/R³

  ! Рекурсия
  if (n > 0) then
    deriv = n * (deriv(n-1,m) * (-dx/R²) + ...)
  end if
  if (m > 0) then
    deriv = m * (deriv(n,m-1) * (-dy/R²) + ...)
  end if
end function
```

**Результат:**
- Точность: 10^-8 - 10^-10
- Работы: 4-8 часов (понять рекурсию, отладить)
